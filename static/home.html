The diagnosis loop

Loss is a signal.
Context is the diagnosis.

The system reads the surrounding evidence before it makes a claim about a vehicle. Every finding is tied back to records that can be inspected.

01 / observe

Start with the relay

Packet receipts, forwarding patterns, queue state, link quality, and mobility are gathered around the same monitored window.

02 / challenge

Let causes disagree

Independent specialists test congestion, wireless degradation, and malicious forwarding hypotheses before the coordinator decides.

03 / protect

Abstain with integrity

When required evidence is missing or contradictory, the system returns insufficient evidence instead of unfairly blaming a node.
